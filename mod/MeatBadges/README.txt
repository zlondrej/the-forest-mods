Meat Badges for The Forest
==========================

INSTALL
  Copy everything in this zip into The Forest's game folder, so that winhttp.dll sits next to TheForest.exe
  (Steam: right-click The Forest > Manage > Browse local files). Works in TheForest.exe and TheForestVR.exe.

  To check it works: start the game, then open BepInEx\LogOutput.log in the game folder. Once you're in the game
  there is a "MeatIcons: size badges on ..." line.

UNINSTALL
  Just this mod: delete BepInEx\plugins\MeatBadges. Everything: see UNINSTALL in ArrowFixes-README.txt.

WHAT IT DOES
  Meat and small meat are told apart in the fire, drying rack, stew pot and door weight prompts: an "L" or "S"
  badge on the meat icon, in the chalk style of the game's icons (vanilla showed the very same picture for both).
  The meat picture is the game's own; only the badges ship with the mod.

SETTINGS
  None.

CREDITS
